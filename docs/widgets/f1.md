# F1 Widget

Displays the next Formula 1 race and the current top-5 driver standings. No configuration required.

## Storage Keys

| Key | Value |
|---|---|
| `f1-cache-{YYYY-MM-DD}T{HH}` | Hourly JSON cache of `{ race, standings }` |

The cache key is built from the browser's local date and hour (`localDateStr(now)` plus `getHours()`), so cached data is reused for the rest of the current local hour. On load the widget shows the cached value when there is one and fetches `/api/f1` only on a miss. Old hourly rows are removed by the server's maintenance job (see [storage.md](../storage.md)).

## Data Source

`GET /api/f1` tries two sources in order and returns the first one that yields a race or any standings (`502` when both fail):

1. [f1api.dev](https://f1api.dev) (primary): `https://f1api.dev/api/current/next` and `https://f1api.dev/api/current/drivers-championship`, fetched in parallel and mapped onto the shape below.
2. The [Jolpica F1 API](https://jolpi.ca) (the maintained Ergast replacement) as fallback: `https://api.jolpi.ca/ergast/f1/current/next.json` and `https://api.jolpi.ca/ergast/f1/current/driverStandings.json`.

Each upstream request has a 7 second timeout and uses Next.js `revalidate: 3600`, so the server-side cache also refreshes hourly.

The route returns:

```ts
{
  race: {
    raceName: string;
    round: string;
    date: string;       // "YYYY-MM-DD"
    time?: string;      // "HH:MM:SSZ"
    Circuit: {
      circuitId: string;
      circuitName: string;
      Location: { country: string };
    };
  } | null;
  standings: DriverStanding[];  // top 5
}
```

`race` is `null` when the season is complete and no next race exists.

## Circuit SVGs

Circuit outline SVGs are served from `/circuits/{circuitId}.svg`. Both sources use Ergast-compatible circuit ids, which match the filenames in `public/circuits/`, so no mapping table is needed. SVGs are from [Jules Roy's f1-circuits-svg collection](https://github.com/julesr0y/f1-circuits-svg) (CC BY 4.0).

The `<img>` is rendered at `w-16 h-16` with `opacity-20` (light mode) / `opacity-60 invert` (dark mode) so it sits as a subtle background element next to the race info.

## Countdown

`countdown(dateStr, timeStr)` computes the diff between now and the race datetime. It returns `"race day"` once the race start has passed, `"today"` when it is less than a day away, `"tomorrow"` when 1 day away, or `"in N days"` otherwise. A race without a time is treated as starting at 12:00 UTC.

## Standings Display

The top 5 standings show position, three-letter driver code, family name, and points, in a compact table-like layout with `tabular-nums` for aligned numbers.

## Scroll Fades

Top and bottom gradient fades are tracked via `ResizeObserver` and scroll events.
